# Paper corpus

`papers/` contains the previously downloaded State Examinations Commission Higher Level Mathematics PDFs. They are retained as source material for later content ingestion and are not currently served by the web app.

The prototype questions in `src/data/papers.ts` are original examples. They are deliberately separate from the PDF corpus so the first UX can be tested before a review and extraction workflow is designed.

The original scraper remains in `/home/cian/Desktop/lc_app/scraper/`.
